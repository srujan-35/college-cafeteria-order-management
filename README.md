## Problem Statement
College cafeterias receive multiple food orders during peak hours. Managing pending orders, processing them in the correct sequence, calculating bills, and tracking completed sales manually can be difficult.

This project implements a menu-driven College Cafeteria Order Management System using C programming.

## Objectives
- Apply a Circular Queue to manage pending orders.
- Apply an array-based Stack to store completed orders.
- Calculate food bills automatically.
- Support undoing the latest order completion.
- Search orders by ID.
- Generate cafeteria summaries and sales reports.

## Data Structures
- **Circular Queue:** Maintains pending orders using FIFO.
- **Array-based Stack:** Maintains completed orders using LIFO.

## Features
1. Place new orders.
2. Display pending orders.
3. Prepare the next order.
4. Display completed orders.
5. Undo the latest completion.
6. Search by order ID.
7. Display cafeteria summary.
8. Generate a sales report.
9. Display food prices.
